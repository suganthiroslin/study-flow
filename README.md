# 📚 StudyFlow

**StudyFlow** is a personal study management web application designed to help students organize questions, topics, and study tasks into simple, trackable checklists.

## 🎯 Vision

The idea behind StudyFlow is to make studying easier to **organize, track, and complete**.

Students often have questions and topics scattered across notes, documents, and different platforms. StudyFlow brings them together into organized study lists where each task can be checked off as it is completed.

## ✨ Features

* 🔐 Login and signup
* 📋 Create multiple study lists
* 📝 Add multiple questions or tasks at once
* 🔢 Automatically process numbered and bulleted questions
* ☑️ Mark completed questions using checkboxes
* ✍️ Completed questions are shown with strikethrough
* 🗑️ Delete individual questions
* 🧹 Delete completed questions
* 🔍 Search questions
* 📊 Track completion progress
* 🌙 Dark-themed user interface
* 🎨 Vibrant and responsive UI
* 💾 Store study data using browser local storage

## ⚙️ How It Works

1. Create an account or log in.
2. Create a study list.
3. Paste your questions or study tasks.
4. StudyFlow converts each question into a checklist item.
5. Mark questions as completed while studying.
6. Track your progress through the progress indicators.
